# Haptic-Rotary-Controller
A ESP32 based haptic rotary controller based on FOC and Scott Bezek's smart knob

Overview: This is a rotary smart knob based off of the spark fun ---- gimbal motor, an esp32 s3, and the tmc6300 FOC motor controller. It is focused on creating a simple FOC device with as little parts as possible which maintaing high quality and modularity. SImilar to the Smart Knob View it feautres the same motor, but it is different in a variety of ways. It features higher quality LED's, More power throughput, A more efficient Buck converter, and a more practical LED layout. It lacks the screen and flexture based press architecture due to those mechanics raising complexity beyond their worth. It also features a 4 Pin Jst Port and 8 pin display port for all of your external device needs.

Assembly- Currently I'm working on a way to assemble this board for myself because it is still pretty high in component count. It is completely 1 sided which provides simplicity from manufacturers and should make it decently cheap to assemble. For 2 of them from JLC-PCB it way about 100 dollars. You could also consider hot air, a PCB-Oven, or a hotplate which would all work for its nature. Some parts are a bit questionable like the Kalih Choc switches which are in the full version but i will likely ship the project with other switch options. The LED's should work properly with all forms of soldering but be careful with hot air. None of the footprints are setup for hand soldering and the TMC6300 is way too low pitch to even be possible. Also this project will be shipped in a version that includes a esp32 Devboard, and a tmc6300 breakout instead of the full parts list. This is a much simpler version this it potentially possible to Handsolder. This version is not recommended as it is less polished but it should still work just it wont have undergone testing as thuroughly.

Cost- This board is overall pretty pricy for all the parts needed. The motor especially, Three Phase Brushless Gimbal Stabilizer Motor, is ultra expensive because spark fun is manufacturing it for a very small community of FOC Developers. It is needed due to its special capabilities and its low cogging that make it optimal for the purpose. Two boards assembled is about 120$ and i plan to potential sell them from JLC-PCB or build them myself and sell them.  All added up i would say with the MOQ of 2 PCB's from JLC-PCB and the 40$ motor you could be in about 200 with all parts added on such as screws, small screen, maybe a stemma device if you want to add on.

Why?, This board is optimal for anyone without a soldering iron that is interested in PCB hardware, FOC, or overall product feel and interesting designs. It can be made into any type of knob with simple CAD skills and creativity, and that is the main goal. It is more universal that Scott Bezek's design which is less customizable.
